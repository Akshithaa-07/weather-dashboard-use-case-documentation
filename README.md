# weather-dashboard-use-case-documentation
Use Case Diagram and Documentation for a Weather Dashboard System – Software Development Internship Task 1

## Internship Task 1

This repository contains the Use Case Diagram and supporting documentation developed as part of my Software Development Internship at CodeOrbit Tech.

## Project Overview

The Weather Dashboard System is a web/mobile application that allows users to search for locations, view current weather conditions and forecasts, save favorite locations, and receive severe weather alerts.

Administrators can manage the weather data source configuration and system-wide alert thresholds.

## Actors

The system contains three primary actors:

- **User** – Searches locations, views current weather and forecasts, manages favorite locations, configures alert preferences, and receives weather alerts.
- **Admin** – Manages weather data source configuration and alert thresholds.
- **Weather Data Provider** – External system that provides current weather and forecast data.

## Use Cases

The documentation covers the following use cases:

1. Search Location
2. View Current Weather
3. View Forecast
4. Save Favorite Location
5. Remove Favorite Location
6. Set Weather Alert Preferences
7. Receive Alert Notification
8. Manage Data Source Configuration
9. Manage Alert Thresholds
10. Provide Weather Data

## Project Scope

The system focuses on current weather conditions and short-range forecasting. Historical weather archives, minute-by-minute live radar tracking, and multiple simultaneous third-party weather providers are outside the defined scope.
